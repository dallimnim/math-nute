# 수학 누테

중학교·고등학교 수학의 단원별 오답을 돌아보고, 비슷한 문제와 심화 문제로 개념을 익히는 학습 웹앱입니다.

## 주요 기능

- **오늘의 누테**: 선택한 학년·과목·단원에서 10문제를 카드 형식으로 풀고, 학습을 완료하면 도장을 기록합니다.
- **오답 살펴보기**: 문제 사진과 풀이, 정답, 오류 유형을 기록합니다.
- **쌍둥이 문제**: 단원과 오답 유형을 돌아보는 유사 연습 문제를 제공합니다.
- **심화 문제**: 사고력과 응용을 위한 단원별 확장 문제를 제공합니다.
- **요약 노트 공유**: 단원 목표 아래에서 요약 노트를 사진으로 올리고, 같은 단원에 올라온 친구 노트를 봅니다.

## 요약 노트 공개 안내

요약 노트 사진과 선택한 별명·설명은 모든 방문자에게 공개됩니다. 사진에 실명, 학교·학원 이름, 얼굴, 연락처, 계정 정보가 나오지 않는지 확인한 뒤 올려 주세요. 업로드 기능은 공개 웹사이트의 서버 저장소가 연결되어야 동작합니다. 정적 HTML로만 배포하면 친구 노트 공유는 사용할 수 없습니다.

## 브라우저에 저장되는 정보

오답 노트, 오늘의 누테 진행과 도장은 현재 브라우저에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다. 문제 사진의 OCR/자동 분석은 제공하지 않으므로 문제 정보와 오류 유형을 직접 입력해야 합니다.
